# Bento Grid

This is my solution to the [Bento Grid challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/bento-grid-RMydElrlOj).

The goal of this project was to build a responsive bento-style layout and recreate the provided design as accurately as possible using HTML and CSS.

## Overview

### Features

- Responsive layout for desktop and mobile devices
- Bento-style grid with cards of different sizes
- Different card arrangements depending on screen size
- Semantic HTML structure
- Custom typography, colors, and spacing

## What I Learned

This project helped me improve my CSS layout skills and gain more experience building responsive interfaces.

**CSS Grid**

I practiced creating complex layouts using CSS Grid, including arranging cards of different sizes and controlling their placement within the grid.

**Responsive Design**

I learned how to adapt a multi-column desktop layout to smaller screens using media queries and different grid configurations.

**Element Positioning**

I gained more experience controlling the size, alignment, and spacing of elements to match the provided design.

**Semantic HTML**

I practiced organizing content using semantic HTML elements and maintaining a clear document structure.

**Working with Design References**

I improved my ability to recreate a design from reference images, paying attention to typography, colors, spacing, and overall visual consistency.
